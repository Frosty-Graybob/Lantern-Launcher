    Players can't connect?
    1. They need to be on the same network as this PC (same router or Wi-Fi). Over the internet needs port forwarding or a VPN, which isn't set up here.
    2. The first time the server starts, Windows Firewall asks whether to let it through. It has to be allowed for private networks. If you clicked Cancel, open Windows Security → Firewall & network protection → Allow an app through firewall and tick Game Launcher Server.
    3. If this PC lists more than one address above (Wi-Fi, Ethernet, a VPN…), use the one on the players' network, usually the first.
    4. Test it: open the address in a web browser on another PC. You should see a page saying the server is running.
